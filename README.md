# Lab Entry Log System

A React application to manage laboratory entry and exit logs.

## Features

- Home Page
- Add Log Entry
- View Log Entries
- Bootstrap UI
- React Router
- Axios API Integration

## Technologies

- React
- Vite
- Bootstrap
- Axios
- React Router DOM

## Installation

bash
npm install
npm run dev

## Backend API

### Add Log Entry

POST

http://localhost:3000/add-log-entry

### View Log Entries

GET

http://localhost:3000/view-log-entry
